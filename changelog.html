plugin-hunter.sh1.7.02026-08-06
  • After disabling a culprit, the whole site is re-enabled and re-tested — the scan stops early once it's healthy, or keeps hunting for the next culprit, so multiple problems are still all found.
  • Identified culprits are now announced and, in manual mode, confirmed before being kept disabled.
  • WooCommerce dependency handling: if the site is still broken with every plugin off and WooCommerce is installed, it's pinned back on and the baseline re-checked (many themes fatal without it), then excluded from the hunt.
  • پس از غیرفعال‌کردن یک مقصر، کل سایت دوباره فعال و آزمایش می‌شود — به‌محض سالم شدن، پویش زودتر متوقف می‌شود وگرنه سراغ مقصر بعدی می‌رود، پس همهٔ مشکل‌ها همچنان پیدا می‌شوند.
  • مقصرهای شناسایی‌شده حالا اعلام می‌شوند و در حالت دستی، پیش از غیرفعال ماندن، تأیید گرفته می‌شود.
  • مدیریت وابستگی ووکامرس: اگر با غیرفعال بودن همهٔ افزونه‌ها سایت هنوز خراب باشد و ووکامرس نصب باشد، ووکامرس دوباره فعال و وضعیت پایه دوباره بررسی می‌شود (بسیاری از قالب‌ها بدون آن ارور می‌دهند) و سپس از پویش کنار گذاشته می‌شود.
plugin-hunter.sh1.6.02026-08-05
  • Binary search now verifies the site is healthy with every plugin disabled before starting, and aborts if the fault is not a plugin.
  • Binary search is now recursive and explores both halves, so it finds every problematic plugin instead of stopping at the first — clean halves are enabled in one cheap check, broken halves are split further.
  • جستجوی دودویی حالا پیش از شروع، سالم بودن سایت را با غیرفعال بودن همهٔ افزونه‌ها بررسی می‌کند و اگر مشکل از افزونه نباشد متوقف می‌شود.
  • جستجوی دودویی حالا بازگشتی است و هر دو نیمه را بررسی می‌کند، پس به‌جای توقف روی اولین مورد، همهٔ افزونه‌های مشکل‌دار را پیدا می‌کند — نیمه‌های سالم با یک بررسی ارزان فعال می‌شوند و نیمه‌های خراب باز هم نصف می‌شوند.
plugin-hunter.sh1.5.02026-08-01
  • Reversed both search strategies: all plugins are now disabled first, then re-enabled to pin down the culprit. Linear reports every problematic plugin, so simultaneous breakages are all caught in one run.
  • Added command-line flags (-d/--domain, -p/--path, -m/--manual, -a/--automate, -l/--linear, -b/--binary, -h/--help) so every prompt can be answered up-front; omitting any still falls back to the interactive prompt.
  • معکوس‌شدن هر دو استراتژی جست‌وجو: حالا ابتدا همهٔ افزونه‌ها غیرفعال می‌شوند و سپس برای یافتن مقصر دوباره فعال می‌شوند. حالت خطی همهٔ افزونه‌های مشکل‌دار را گزارش می‌کند تا خرابی‌های همزمان همگی در یک اجرا شناسایی شوند.
  • افزودن پرچم‌های خط فرمان (-d/--domain، -p/--path، -m/--manual، -a/--automate، -l/--linear، -b/--binary، -h/--help) تا بتوان همهٔ ورودی‌ها را مستقیم داد؛ هر ورودی‌ای که داده نشود، همچنان به‌صورت تعاملی پرسیده می‌شود.
